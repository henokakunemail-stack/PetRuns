# PetWalk User App

Flutter app untuk Pet Owner. Dibuat dengan Riverpod.

## Generate platform folders

```bash
# Setelah menginstall Flutter SDK, jalankan dari root mobile/:
flutter create --platforms=android,ios --org com.petwalk apps/user_app
# Ini akan menambahkan folder android/, ios/, dan meng-overwrite main.dart
# (sudah kita punya versi custom, cukup keep main.dart yang ada & re-add
#  platform-specific code kalau perlu)
```
